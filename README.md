# 场景融字导演

用于 Vlog 封面、旅行照片、生活摄影和创意海报的提示词 Skill：先设计画面，再让醒目大字成为场景里的一种材料。

当前版本：**1.2.0**（2026-10-18）。本次更新增加三套艺术方向：电影感生活封面、创意海报、日常 Vlog 封面；同时保留局部修正的样式继承规则。

支持已有图融字、无字底图与加字两阶段设计、长句语义拆分，以及字太小、笔锋跨边界、贴字突兀等问题的定向修正。默认一次给出三套有明确差异的提示词，而不是同一方案换颜色。参考包括木门刷字、撕纸标题、云朵字、奶泡、雨窗、湿沙和灯笼。

## 安装与使用

将本仓库目录放入支持 Agent Skills 的客户端技能目录，确保入口为 `scene-lettering-director/SKILL.md`。例如 Codex 可放入 `~/.codex/skills/scene-lettering-director`，随后刷新技能列表或开启新会话。

```text
使用 $scene-lettering-director。
我有一张夜市照片，左上有两盏大纸灯笼。
想做“人间烟火”四个大字，要醒目，但像真的写在灯笼上。
只给我可复制的编辑提示词。
```

没有底图时可直接描述场景，要求分别输出无字底图与融字提示词。本技能不内置生图接口、API 密钥或模型，不依赖本地 ComfyUI 节点；生成图片需使用客户端已有且获授权的工具。

入口：[SKILL.md](SKILL.md)。完整示例：[咖啡奶泡融字](references/coffee-example.md)。严格像素保真与实际生成后的验收边界在入口中说明。

## 验证范围

1.0.0 的综合实测包含 12 类任务、24 次文字对照；实图部分为 3 类共同底图、每组各两次重复，共 12 张融字图。观察到沙滩长句的分行层次有局部改善；木门、雨窗未证明整体优于无 Skill。执行者评审为非盲，独立人工盲评、客户端自动触发及其他图片后端尚未验证。这些旧结果不当作 1.1.0 的新成图验收。

1.1.0 针对实测中“只修尾笔却新增暖白刷漆”的问题修正文档。1.2.0 在此基础上加入三套艺术方向；本次只完成规则与格式核验，未新增成图实验，不据此宣称三套方向的视觉质量或费用改善。
