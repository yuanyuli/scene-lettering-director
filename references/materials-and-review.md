# 载体选择与定向修正

## 用场景决定材料

| 场景与载体 | 可用的成字方式 | 设计与验收重点 |
| --- | --- | --- |
| 深色木门 | 暖白粗刷漆，木纹少量透过 | 竖排适应门板，末字与尾笔不伸向袖子或门外 |
| 室内、日记感拼贴 | 顶部撕纸标题层，墨色渗入纤维 | 先做空白纸层再写字，检查纸沿遮头和卷边阴影；新增纸层会改构图 |
| 老街与蓝天 | 相连积云形成字的笔画，蓝天形成字腔 | 标题与楼沿、树冠之间有完整天空，云絮也计入边界 |
| 大杯奶泡 | 可可粉筛出粗手写字 | 深粉与浅泡沫对比，字离杯沿一圈泡沫，透视跟随液面 |
| 结露车窗 | 手指擦开雾气，笔道透出窗外暗色 | 利用深浅反差，水珠沿笔道聚集，末字避开窗框与脸 |
| 连续湿沙 | 木枝划出凹痕，堆沙、沟槽暗部与湿润反光 | 遵循沙面透视，避开浪线、脚印和人物；别把凹痕画成浮空字 |
| 纸灯笼 | 颜料刷字，随纸曲率、褶皱受光 | 两只灯笼可分配“人间”“烟火”，明确先左后右，每字完整落在纸面 |

这些是设计候选，不是默认颜色或默认材质，也不是可保证成功的预设。已有蓝色贝壳字时，修尾笔仍保留蓝色贝壳，不因为背景是湿沙就改成沙槽；雨窗上的浅金颜料字也不必改成擦雾字。选择其他载体时同样明确“怎样形成字”和“在哪里结束”，例如布料刺绣、霜面擦痕或纸雕；未经生成复核的方向标为设计提案。

## 长句拆分

“把日常拍成电影”可按语义排为“把日常／拍成／电影”；竖长木板可排“出／发／吧”。长句也可跨多个载体，但需交代每个载体的准确文字、阅读次序和独立边界。已有空间装不下时，不靠让笔锋跨进树冠、人物或不同背景来掩盖问题。

## 由问题决定改动

| 实际问题 | 下一轮处理 |
| --- | --- |
| 文案正确但缩略图看不清 | 先在原有样式内调整字号、字间距或重点；换色、换材料、换载体属于另一个设计方向，需符合用户改动范围 |
| 末字贴袖、贴框、贴树线 | 保留样式与排布，优先收短尾笔或微移末字，明确实物间隔；必要时才移动整组 |
| 材质丰富但字形散掉 | 简化纹理和外沿装饰，恢复关键笔画、字腔与字间空隙 |
| 像漂浮贴纸 | 明确材料附着/成形方式、同一光源、曲面与透视，检查是否真的遵循 |
| 人脸、物件或构图漂移 | 对照原图记录变化；严格保真需求改用可验证的遮罩或确定性图层 |
| 生成结果有额外招牌字 | 指出额外字的位置；按用户需求决定清理、裁切或保留，不宣称全图只剩指定文字 |

不要用“高级、自然、有设计感”替代具体材料、位置、阅读路径和受光描述。对不满足要求的样张直接标注问题，不把用户未评价的结果写成已认可。

## 验收与修正记录

实际生成后按下表留简短记录即可，无需新增执行框架：

| 项目 | 记录内容 |
| --- | --- |
| 原文与重组全文 | 原文；按先后次序连起各行后的全文；分别核对字词、标点和大小写 |
| 展示宽度 | 目标宽度，或 320/390 像素宽的等比预览；不放大时哪些字读不清 |
| 边界 | 全部笔画与外缘是否在指定载体内，末字与人物、脚部、窗框等是否留有可见间隔 |
| 保留项与变化 | 已确认的颜色、材料、分行、人物和构图；实际发生了什么变化 |
| 修正 | 本轮具体问题、只允许改动的项目、结果，以及尚未解决的问题 |

位图可检查标点外形，但不能反向证明 Unicode 编码。预览宽度是可复现的观察条件，不等于已经通过客户端展示或真实平台上传验收。

已有样张与经验只在能追溯输入、提示词及结果时作为验证证据；其余保留为设计提案。记录成功和失败，不用新示例伪装成实跑结果。

## 修正示例：门板尾笔越界

已观察的文字测试问题：用户只描述“吧”的尾笔跨到白袖子，修正提示词却新增“暖白粗刷漆”；用户没有提供这个字色或材质。新增样式即使放在说明中标为建议，也会改变实际送入编辑模型的提示词。

对应修正写法：“保留上一版已确认的颜色、材质、字号和排布，只将‘吧’的右侧尾笔收回门板内，与白袖子留出可见木纹间隔，其余设置沿用。”这是修正提示词示例，不是已完成的修图结果。从无字底图执行时，同时提供上一版提示词或样式参考，避免只靠文字指代。
