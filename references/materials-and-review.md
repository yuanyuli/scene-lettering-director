# 载体选择与定向修正

## 用场景决定材料

| 场景与载体 | 可用的成字方式 | 设计与验收重点 |
| --- | --- | --- |
| 深色木门 | 暖白粗刷漆，木纹少量透过 | 竖排适应门板，末字与尾笔不伸向袖子或门外 |
| 室内、日记感拼贴 | 顶部撕纸标题层，墨色渗入纤维 | 先做空白纸层再写字，检查纸沿遮头和卷边阴影；新增纸层会改构图 |
| 老街与蓝天 | 相连积云形成字的笔画，蓝天形成字腔 | 标题与楼沿、树冠之间有完整天空，云絮也计入边界 |
| 大杯奶泡 | 可可粉筛出粗手写字 | 深粉与浅泡沫对比，字离杯沿一圈泡沫，透视跟随液面 |
| 结露车窗 | 手指擦开雾气，笔道透出窗外暗色 | 利用深浅反差，水珠沿笔道聚集，末字避开窗框与脸 |
| 连续湿沙 | 木枝划出凹痕，堆沙、沟槽暗部与湿润反光 | 遵循沙面透视，避开浪线、脚印和人物；别把凹痕画成浮空字 |
| 纸灯笼 | 颜料刷字，随纸曲率、褶皱受光 | 两只灯笼可分配“人间”“烟火”，明确先左后右，每字完整落在纸面 |

这些是实跑探索过的方向，不能保证新图一次成功。选择其他载体时同样明确“怎样形成字”和“在哪里结束”，例如布料刺绣、霜面擦痕或纸雕；未经生成复核的方向标为设计提案。

## 长句拆分

“把日常拍成电影”可按语义排为“把日常／拍成／电影”；竖长木板可排“出／发／吧”。长句也可跨多个载体，但需交代每个载体的准确文字、阅读次序和独立边界。已有空间装不下时，不靠让笔锋跨进树冠、人物或不同背景来掩盖问题。

## 由问题决定改动

| 实际问题 | 下一轮处理 |
| --- | --- |
| 文案正确但缩略图看不清 | 加大重点词与字重，提高字和载体的明暗对比，必要时换载体或分行 |
| 末字贴袖、贴框、贴树线 | 从原底图复测，上移或内收整组，明确尾笔收束与实物间隔 |
| 材质丰富但字形散掉 | 简化纹理和外沿装饰，恢复关键笔画、字腔与字间空隙 |
| 像漂浮贴纸 | 明确材料附着/成形方式、同一光源、曲面与透视，检查是否真的遵循 |
| 人脸、物件或构图漂移 | 对照原图记录变化；严格保真需求改用可验证的遮罩或确定性图层 |
| 生成结果有额外招牌字 | 指出额外字的位置；按用户需求决定清理、裁切或保留，不宣称全图只剩指定文字 |

不要用“高级、自然、有设计感”替代具体材料、位置、阅读路径和受光描述。对不满足要求的样张直接标注问题，不把用户未评价的结果写成已认可。
